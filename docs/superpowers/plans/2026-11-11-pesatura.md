# Pesatura — Piano di costruzione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aggiungere all'esperimento la sezione **Laboratorio** con la **Pesatura**: analisi riusabili di quattro tipi (Aliquota, RWC, % sostanza secca, Vasi), sessioni di pesata sequenziali (anche a voce), riepilogo, archivio, curva di ritenzione dei vasi ed export Excel.

**Architecture:** Quattro tabelle nuove su Supabase con RLS sui ruoli esistenti (`is_membro`, `puo_scrivere`, `puo_configurare`). Tutti i calcoli (RWC, sostanza secca, tampone, % di capacità di campo, curva, controlli, sequenza della pesata, parser della voce) sono funzioni pure in `src/domain/pesatura/`, testate da sole. Le pagine leggono e scrivono **solo online** con TanStack Query, senza coda locale. L'Excel riusa il modello `Cartella` e `scriviCartella`, il PNG del grafico riusa `svgInPng`.

**Tech Stack:** React 19, TypeScript, React Router 7, TanStack Query 5, Supabase (Postgres + RLS, pgTAP), Vitest + Testing Library, ExcelJS (già usato), Web Speech API (`SpeechRecognition`, `speechSynthesis`), Lucide.

**Spec:** `docs/superpowers/specs/2026-11-11-pesatura-design.md`

## Global Constraints

- Interfaccia in italiano semplice, nello stile di `PRODUCT.md` / `DESIGN.md`: bersagli ≥ 44×44 px, uso con una mano, contrasti decisi, niente emoji decorative.
- **Solo online**: nessuna coda locale e nessuna lettura in cache persistente per la Pesatura. `src/lib/coda/` e `src/lib/cachePersistente.ts` non si toccano.
- Senza rete la sezione mostra `Sei senza rete: la Pesatura funziona solo online.` e disattiva i salvataggi.
- Un salvataggio fallito lascia il valore nel campo, mostra l'errore e non passa al campione successivo.
- Permessi: proprietario e rilevatore creano sessioni e pesi; il rilevatore corregge ed elimina solo i **pesi propri**; impostazioni, campioni e chiusura di una sessione li gestiscono chi l'ha creata e il proprietario; il lettore legge ed esporta. L'autore (`creato_da`) si salva su ogni peso.
- Ogni sessione **copia** titolo, tipo, unità e impostazioni dell'analisi quando nasce. Il tipo di un'analisi non cambia dopo la prima sessione. Un'analisi con sessioni non si elimina: si archivia.
- Unità di peso per analisi: `g` (default) o `mg`.
- Formule: RWC = (fresco − secco) / (turgido − secco) × 100; sostanza secca % = secco / fresco × 100; % CC = (peso − secco) / (CC − secco) × 100; peso a p % CC = secco + p/100 × (CC − secco).
- Voce: lingua `it-IT`, comando **"avanti"**, decimali con **"virgola"**, **"indietro"** torna al campione precedente; per i vasi in asciugatura "peso \<n\> \<umidità|tensione\> \<n\> avanti".
- Laboratorio: nella pagina compaiono solo le funzionalità già costruite (niente voci "in arrivo"). Icona `FlaskConical`.

## Review Focus

1. **Due persone pesano lo stesso campione** (stessa replica e stesso tipo di peso): il secondo salvataggio va in conflitto sull'indice unico (23505). Deve mostrare `Questo peso è già stato inserito da un'altra persona: ricarica la sessione.` e non sovrascrivere in silenzio. → test in Task 5.
2. **Una lettura del sensore fuori dal campo misurato** (per esempio −80 kPa con punti tra −5 e −50): la curva estrapola. Il peso va mostrato con l'avviso `fuori dai valori misurati`, non come dato sicuro. → test in Task 4.
3. **Numero detto a voce ambiguo o parziale** ("zero virgola", "avanti" da solo, "cinquanta tre avanti", "53.2"): non deve salvare un numero inventato. → test in Task 11.
4. **Eliminare una pianta che ha pesate**: la pianta non deve più risultare eliminabile in Impostazioni (la RPC `piante_non_eliminabili` va estesa), altrimenti l'utente riceve un 23503 incomprensibile. → test in Task 2.
5. **Analisi in unità mg con il rapporto del tampone in mL/g**: i mL vanno calcolati sul peso convertito in g (0,1 mL per 10 mg con 10 mL/g), non sul numero grezzo. → test in Task 3.

### Task 4: Curva di ritenzione e pesi target

**Files:**
- Create: `src/domain/pesatura/curva.ts`, `src/domain/pesatura/curva.test.ts`

**Interfaces:**
- Consumes: `percentualeCC`, `pesoAPercentualeCC` (Task 3); `CampionePesatura`, `Peso`, `Sensore` (Task 3).
- Produces:
  ```ts
  export type ModelloCurva = 'lineare' | 'logaritmico'
  export interface PuntoCurva { lettura: number; pcc: number }
  export interface Curva { modello: ModelloCurva; a: number; b: number; r2: number | null; n: number; min: number; max: number }
  export interface Vaso { campione: CampionePesatura; secco: number | null; cc: number | null; punti: PuntoCurva[] }
  export const modelloPer = (s: Sensore): ModelloCurva => s.tipo === 'tensione' ? 'logaritmico' : 'lineare'
  export function vasiDaPesi(campioni: CampionePesatura[], pesi: Peso[]): Vaso[]
  export function adattaCurva(punti: PuntoCurva[], modello: ModelloCurva): Curva | null
  export function pccDaLettura(c: Curva, lettura: number): number
  export function equazione(c: Curva, sensore: Sensore): string
  export interface CurveSubstrato { substrato: string; vasi: Vaso[]; media: Curva | null }
  export function curvePerSubstrato(vasi: Vaso[], modello: ModelloCurva): CurveSubstrato[]
  export interface PesoTarget { vaso: string; peso: number | null; fuoriCampo: boolean }
  export interface RispostaConsulta { substrato: string; vasi: PesoTarget[]; media: number | null; fuoriCampo: boolean }
  export function consultaPerCC(gruppi: CurveSubstrato[], p: number): RispostaConsulta[]
  export function consultaPerLettura(gruppi: CurveSubstrato[], lettura: number, modello: ModelloCurva): RispostaConsulta[]
  export const PERCENTUALI_TABELLA = [100, 80, 60, 50, 40] as const
  ```
- Regole:
  - **Modello.** La curva esprime la % CC (y) in funzione della lettura (x): `lineare` y = a + b·x, `logaritmico` y = a + b·ln|x|. Si adatta con i minimi quadrati.
  - **Validità.** Servono almeno 3 punti con x distinti. Nel logaritmico i punti con x = 0 si scartano. Con meno punti validi `adattaCurva` restituisce null.
  - **R².** r2 = 1 − SSres/SStot, e vale null se SStot = 0. `min` e `max` sono gli estremi delle x usate.
  - **Punti dei vasi.** `vasiDaPesi` prende il peso secco e la capacità di campo della replica 1. Ogni peso `asciugatura` con una `lettura` non null diventa un punto con pcc = `percentualeCC(valore, secco, cc)`. Se mancano secco o cc, il vaso non ha punti. I punti si ordinano per `misurato_il`.
  - **Curva media.** La curva media di un substrato si adatta a **tutti i punti dei suoi vasi messi insieme**. Il substrato vuoto o null si chiama `Senza substrato`.
  - **Consultazione per % CC.** `consultaPerCC` calcola, per ogni vaso con secco e cc, `pesoAPercentualeCC`. La media è la media aritmetica dei pesi non null. Qui `fuoriCampo` è sempre false.
  - **Consultazione per lettura.** `consultaPerLettura` usa la curva del vaso se esiste, altrimenti la curva media del suo substrato, per ottenere la pcc. Poi calcola il peso con `pesoAPercentualeCC`. `fuoriCampo` è true se la lettura è fuori da [min, max] della curva usata. Senza curva, peso null.
  - **Equazione.** `equazione` scrive ad esempio `%CC = 112,4 − 18,3 · ln(kPa)  (R² 0,97, n 14)`, con la virgola decimale.

  - Punti y = 100 − 20·ln x su x ∈ {5, 10, 20, 40}: con il modello logaritmico dà a ≈ 100 e b ≈ −20.
  - Con 2 punti, `adattaCurva` restituisce null.
